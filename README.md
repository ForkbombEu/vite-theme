# Project placeholder

A small Vite-powered holding page inspired by stark European developer-studio typography.

## Local development

```sh
npm install
npm run dev
```

Run `npm run build` to create the production site in `dist/`.

## Deployment

The workflow in `.github/workflows/deploy.yml` builds and deploys `main` to GitHub Pages. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
