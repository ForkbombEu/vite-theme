Forkbomb theme for Vite & VitePress

One visual system, packaged as semantic CSS tokens, reusable layout patterns, and a VitePress DefaultTheme extension.

Start using it Read the visual contract

A system an agent can apply

The theme separates source-faithful primitives from reusable patterns. Agents can import the whole layer, override named tokens, or use the documented class vocabulary without copying page-specific CSS.

Semantic design tokens

Colors, type, spacing, shadows, timing, and container sizes use stable --fb-* names.

Plain Vite entry point

Import @forkbomb/vite-theme/style.css, then compose layouts with the fb- class vocabulary.

VitePress theme extension

Export the packaged theme from .vitepress/theme/index.ts to gain the brand bar, footer, palette, typography, and Markdown styles.

Safe scaffold installer

The installer preserves existing content by default, supports a dry run, and only overwrites configuration when explicitly forced.

The Forkbomb palette

Deep navy carries technical depth, royal blue owns navigation and structure, mint marks action and state, while white and cloud fields keep documentation readable.

Install once, keep the method

The package exposes narrow entry points for Vite and VitePress, plus a copy-based scaffold for repositories that prefer local ownership of their documentation theme.

Vite

npm install @forkbomb/vite-theme

// main.ts
import '@forkbomb/vite-theme/style.css'

VitePress

// .vitepress/theme/index.ts
export { default } from '@forkbomb/vite-theme/vitepress'
